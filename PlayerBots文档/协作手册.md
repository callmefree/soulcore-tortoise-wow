# SoulCore PlayerBots 分支移植 — 协作手册

> 本文件与项目资料一同存放在 WorkBuddy 资产空间 `SoulCore-PlayerBots/` 子目录，供任何地点的组员接入维护。

## 1. 项目是什么
SoulCore 是基于 Turtle WoW（MaNGOS 1.12 魔改）的魔兽私服。本项目在做 **PlayerBots 模块分支移植**：把 `Shyalya/tortoise-wow` 的 `playerbots-integration-gh` 分支移植进我们的 fork，并保持与 **Eluna Lua 引擎共存**（bot 上线不触发真实玩家的 Eluna 登录/聊天事件）。

- 代码仓库：https://github.com/callmefree/soulcore-tortoise-wow
- 资产空间（本文档所在）：WorkBuddy 项目资产空间 → `SoulCore-PlayerBots/`

## 2. 分支策略（硬隔离红线）
- `main`：稳定主线，对应上游 `Penqle/tortoise-wow`。
- `feature/playerbots`：本次移植工作分支。**验收通过前不得 merge 回 main**。
- 任何人推代码**只推 `feature/playerbots`**，禁止直推 `main`。
- 资源隔离：不碰生产 3306 四库；测试用 3307 满配参照库（`E:\11111\Twow1181Bots`）；测试服端口 8091/3725，独立运行目录。

## 3. CI 编译（无需本地 VS）
推送 `feature/playerbots` 自动触发 `.github/workflows/playerbots-branch-build.yml`：
- 矩阵：**Linux(ubuntu-22.04) × Windows × BUILD_PLAYERBOTS=[ON,OFF] = 4 个任务**。
- 产物名：`soulcore-pb-<ON|OFF>-<linux|windows>`（14 天保留，不覆盖主线 `soulcore-tortoise-wow` 产物）。
- 查看：GitHub → Actions → run 列表。
- 依赖由 workflow 自理：Linux 装 `libboost-thread/filesystem/system`；Windows 用 vcpkg 装 ACE+Boost 并打 ACE `C2694` patch。

## 4. 如何介入
### 4.1 只看资料 / 提建议（轻量）
- 资产空间：在 WorkBuddy 加入本项目即可看到 `SoulCore-PlayerBots/` 下所有文档。
- 代码：GitHub 仓库 public，可 fork/clone，提 issue 或 PR。

### 4.2 直接改代码 + 跑 CI（推荐）
1. 让项目负责人把你加为 **GitHub collaborator**（仓库 Settings → Collaborators）**和** **WorkBuddy 项目成员**（看资产空间）。
2. clone 并切分支：
   ```
   git clone https://github.com/callmefree/soulcore-tortoise-wow
   git checkout feature/playerbots
   ```
3. 改代码 → `git push origin feature/playerbots` → 自动跑 4 任务 CI。
4. **推 `.github/workflows/` 下的文件需要 PAT 带 `workflow` scope**，否则 GitHub 拒绝（仅 `repo` scope 不行）。
