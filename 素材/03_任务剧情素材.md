# 03 任务与剧情素材（逍遥端本体）

> 来源：`攻略大全/特殊任务.txt`、`历次版本更新内容.txt`（逍遥魔兽 3.35 本体，非 ARPG 层）
> 用途：**剧情演绎手法**参考 —— Turtle 1.12 原生有灰烬使者/开门等剧情，我们的自定义任务可借鉴其"护送+跟随+大场面+台词演出"结构。

---

## 1. 灰烬使者任务链（逍遥端独有扩展，28 级~80 级，22+ 任务）

**叙事骨架**（可作为"史诗级任务链"的模板）：

| 阶段 | 任务 | 手法 |
|---|---|---|
| 序章 28级 | 麦克莱斯的钱袋 | 副本内尸体 NPC 触发，拾取物起手 |
| 铺垫 | 尘封的历史 / 瑞泽布水晶 / 麦格尼·铜须 | 跨地图跑腿 + NPC 台词演出 |
| 打造 | 收集材料 / 神剑出世 | 需要提前备材料（秘银锭30/黄水晶10/砂轮10/碎片5）；**跟紧 NPC 看铸剑动画** |
| 转折 | 愤怒的雷诺 / 达利安的坚毅 | **伪装混入**（买士兵服）；任务间大量剧情补白（雷诺弑父真相） |
| 60级 | 恐惧魔王 / 达里安的约定 / 重返血色教堂 / 堕落的灰烬使者 / 达里安的激励 | **怪物下跪**演出；密室开门；关键 NPC 证词 |
| 70级 | 爱的救赎 / 黎明之光 | **大场面战役**（跟随 NPC 攻打圣光之愿礼拜堂，巫妖王登场） |
| 80级 | 瓦解力量1-3 / 决战巫妖王 / 新的征途 | 进副本击杀指定 boss 作为前置；最终奖励橙武 |

**可借鉴手法**：
1. 任务奖励放"**特殊任务天赋点**"（1 点/条线，形成全局养成资源）
2. 前置任务跨 3 个资料片等级段，长线叙事
3. 用 NPC 台词 + 剧情补白文档（攻略）撑起世界观
4. 关键战斗用"跟紧 NPC"防丢机制（护送距离 50→80 码）

## 2. 萨拉迈尼任务链（38 任务，瓦里安剧情）

- 黑龙 MM 副本掉落"安度因的日记"触发 → 穿越回过去 → 角斗场 3V3 → 厄运之槌挑战 → 雷霆崖 → 灰谷 → 达纳苏斯 → 塞拉摩 → 米奈希尔港海战 → 萨多尔大桥 → 暴风城揭露阴谋 → 融合 → 决战奥妮克希亚 → 获得萨拉迈尼。
- **核心手法**：整条线=一部长电影，每段有专属场景/台词/小演出（记忆恢复法阵、双人融合等）。
- 奖励：萨拉迈尼（双手橙武）+ 变身瓦里安；可拆分沙拉托尔+埃雷梅尼（主副手）。

## 4. 单刷向 Boss 调整思路（大量可抄的数值策略）

| 原问题 | 逍遥端解法 |
|---|---|
| 小怪 99% 免伤（ICC 亡语者女士） | 改 80% 减伤，全职业可击杀 |
| 12 秒控制 | 缩短至 5 秒 |
| 秒人技能（奥杜尔闪电球/阿克死亡一指） | 取消/降伤害 |
| 瓦格里抓人扔下平台 | 直接取消该 AI |
| 单刷 boss 无敌循环（太阳井老一） | 残血进传送门内部战 |
| 卡拉赞象棋 | 简化成控棋击杀国王 |
| 战车/载具强度 | 血量输出 ×3 |

> 1.12 落地：Turtle 端 creature_template/AI 均可 SQL 调整；Eluna boss 事件可做更精细的动态平衡。

## 5. 世界氛围类（低成本高回报）

- **主城喊话机器人**：NPC 每隔 3-5 分钟刷玩家式喊话 → 主城不冷清（1.12 Eluna OnUpdate/定时器即可）
- **野外任务机器人**：NPC 模拟玩家做任务（可买装备/切磋/求 buff）
- **拍卖行机器人**：自动上架/购买，维持拍卖行活跃
- **全职业宠物天赋**：宠物 20 级后每 3 级 +1 天赋点
- **钓鱼彩蛋**：特定鱼群 0.5% 掉稀有武器（"灰尘使者"）+ 成就
