# 01 暗黑3与POE玩法系统（核心素材）

> 来源：ARPG 暗黑逍遥（逍遥 3.35 + ARPG 魔改层，2022-12 版）
> 本篇描述每个系统的**玩法规则、数值、机制**；物品 ID 与表结构见 `02_装备物品体系.md`；怎么落到我们的 1.12+Eluna 见 `04_移植评估与落地建议.md`。

## 1. 符文系统（暗黑2 风格，1~33 号）

- **玩法**：1~33 号符文（El 艾尔 → Zod 萨德），**世界掉落**，用法=直接附魔到装备上（原生附魔机制，无需额外 UI）。
- **兑换**：随身商人提供"高一级符文换低一级"（向下兑换，避免脸黑卡进度）。
- **稀有度设计**：符文编号越高 quality 越高（1-6 号绿、7-16 号蓝、17-24 号紫、25-32 号橙、33 号红），33 号 Zod 是最稀有目标物。
- **用法延伸**：传家宝需要指定符文激活（每件传家宝标注所需符文号，制造"打宝→符文→解锁传家宝"循环）。
- 全部条目见 `数据/符文清单.txt`。

## 2. 四色宝石（暗黑3 风格）

- 4 种颜色对应 4 属性：红宝石=力量、黄宝石=智力、绿宝石=敏捷、紫宝石=耐力。
- 每色 5 级（普通/完美/贵族/帝国/皇家）+ **宝石精华**（顶级材料）。
- **限制**：每种颜色宝石最多镶嵌 2 枚（防纯堆单属性）。
- 数据：`item_template 300501~300530` 段（见 02）。

## 4. 传奇诅咒宝石（POE 参照，11 颗）

- **定位**：流放之路风格，属性强但带**负面效果**（诅咒），最多只能镶嵌 1 枚（抉择玩法）。
- 5 级，由**传奇诅咒宝石商人**（NPC 180012）兑换。
- 具体条目在本端数据库未按"诅咒宝石"命名检索到（可能用别称），建议后续开服对照商人售卖清单补全。

## 5. 宝石兑换/合成链（暗黑3 宝石系统骨架）

```
宝石书页（世界掉落）→ 合成 宝石书（1-6 级）→ 传奇宝石商人兑换对应等级宝石
                                       ↓ 另路
                        3 颗 N 级宝石 → 1 颗 N+1 级宝石
                        高等级宝石 → 反向镶嵌拆解（回收）
```
- 6 级传奇宝石获取极难 → 全服稀有目标物。
- 1.12 实现时可用 Eluna 自定义物品 + 合成脚本复刻（无需 C++）。

## 6. 三色球（POE 核心机制，本端最大亮点之一）

| 球 | 效果（POE 原版语义） | 本端数值 |
|---|---|---|
| 暴击球 | +全域暴击率 | 每颗 +5% 全域暴击率 |
| 狂怒球 | +攻速 +伤害 | 每颗 +5% 攻击速度 +5% 全域伤害 |
| 耐力球 | +护甲 +抗性 | 每颗 +5% 护甲 +10 元素抗性 |

- **获取**：天赋第一页学习（被动常驻）；**装备词缀**大量产出：击中/击杀/被击中 2% 几率得球；每 15 秒自动得 1 球；死亡不掉球/持续时长词缀。
- **联动**：词缀池有"每颗球为你增加 X% 伤害/回复"的联动词缀，形成构筑深度（堆球 vs 堆直伤）。
- 1.12 实现建议：Eluna aura 模拟（玩家身上挂 3 层计数器 + 动态调整属性），或 Turtle 自带的自定义 buff 机制。

## 8. 紫装随机词缀（POE 词缀系统）

- **规则**：所有紫装（quality 4）掉落时带 **2 条随机附魔**；物品等级越高词缀属性越强。
- **词缀池**（270+ 条，分两组模板 9041/9045，权重 0.1~0.457 区分稀有度），内容大类：
  1. **基础属性**：生命/能量回复 +6%、全属性/单属性 +1%、攻速/施速/暴伤/移速 +1%、护甲/命中 +1%
  2. **元素抗性**：神圣/火焰/自然/冰霜/暗影/奥术抗性 +10 点、全元素 +5
  3. **状态触发**：火焰伤害 2% 燃烧、冰霜 2% 冰封、暗影 2% 腐烂、自然 2% 感电、物理 2% 内伤、元素 1% 感电
  4. **三色球联动**：击中/击杀/被击中 2% 得球、每 15 秒自动得球、每颗球 +1% 伤害/回复、球持续时间 +5%
  5. **宠物**：宠物伤害 +2%、宠物减伤 5%、宠物攻速 +1%
  6. **特殊**：施法时保持法力回复、战斗中生命回复、猛攻触发（被攻击 2% 触发 4 秒猛攻：移速 25%/施速 15%/攻速 15%）
- 完整词缀中文列表在 `原文备份/ARPG暗黑逍遥简单攻略_全文.txt`。

## 9. 远古 / 太古升级链（暗黑3 装备等级）

```
紫装（普通）
  └─ 使用 ★混沌石★ ── 5% → ★远古★（属性 +20%，自带 1 孔）
                        └ 0.2% → ★太古★（属性 +20% 再递加，自带 2 孔）
```
- 远古 = 原版紫装 entry+100000（名字后缀 `|cFF007FFF★远古★`，青色）
- 太古 = 原版紫装 entry+200000（名字后缀 `|Cffcc3299★太古★`，品红）
- **属性递加**：远古比普通高 20%，太古再叠（同词缀更强），加孔位 → 养成天花板由"刷太古"决定。

## 10. 红色传奇装备（暗黑3 传奇）

- **定位**：属性"稀奇古怪"（特效向）的红色名字装备，分**法系版/战系版**两套（重铸石互转）。
- **等级体系**：每件 5 级（★~★★★★★）× 3 品质（普通 绿★ / 远古 蓝【远古】 / 太古 橙【太古】）= **15 个条目/件**（entry 302000+ / 312000+ 段）。
- **掉落**：世界小概率；BOSS 40% 掉落。
- **命名例**：`|cFFFF0000杨的反曲弓|cFF33FF00★★`、`|cFFFF0000黎明|cFF0066FF【远古】★`
- 总数：302xxx 段 989 条（约 66 件红装 × 15）。

## 11. 副本通行证门控（暗黑3 秘境式进度）

- **规则**：每级副本对应一套专属套装（死亡矿井→迪菲亚皮甲、哀嚎→毒蛇的拥抱、血色→血色十字军链甲、黑石深渊→角斗士、T0/T0.5/ZG/T1/T2/AQ/T3/T4/T5…）；**集齐上一档套装 → 获得进入下一副本的通行 BUFF**；**越级进本无 BUFF 会被秒杀**。
- **效果**：副本进度=装备进度=唯一成长路径，杜绝"满级一身传家宝直接砍最终副本"。
- 完整对照表：`数据/套装掉落对照表.txt`（334 行，T0~T5+ 全量）。
- 1.12 实现：Eluna `OnMapEnter` 检查 buff + 移除/秒杀逻辑即可复刻。

## 12. 套装重铸（POE 转化机制）

- 集齐套装部件难 → 提供 **重铸石**：把套装 A 部件转成同套装其他部件；**5% 概率装备消失**（风险赌注）。
- 变体：红装法系↔战系互转（重铸石）。

## 13. 拉玛兰迪的礼物（打孔器）

- 对武器使用 = 打孔（暗黑3 同名道具直译）；用于"符文/宝石插孔"养成。
- 1.12 用 Eluna `ModifyEnchantment`/`SetSocket` 类 API 或临时附魔模拟。

## 14. 赫拉迪克方块（核心养成容器，quality 7）

- **装备后**：可以使用重铸石/混沌石对装备升级、转换；同时**分解/选矿/研磨技能被禁用**（防偷鸡：方块路线与制造路线二选一）。
- 绑定：分解、选矿、研磨为自动学会的专业技能。
- 功能面 = 暗黑3 卡奈魔盒（升级/重铸/提取）+ 暗黑2 方块（合成）。
- 1.12：Eluna 物品 use 事件（本项目已实测 OnItemUse 全链路，语义是 return false 阻止施法）实现整套 UI。

## 15. 全职业宠物（暗黑3 追随者）

- 全职业自带 1 只宠物，**狡诈/狂野/坚韧** 3 系选 1（对应攻/守/速方向）；宠物有天赋点（20 级后每 3 级 +1，不可重置——谨慎加点）。
- 示例物品：`60011 召唤狮子`、`60012 召唤乌龟`（quality 5）。
- 1.12：Eluna 召唤类实现（Turtle 原生有宠物系统可借力）。

## 16. 全武器（暗黑3 武器自由）

- 除双武器（蛋刀/萨拉迈尼类）外，**全职业可用所有武器**；远程武器需在职业训练师学"自动射击"。
- 1.12 Turtle 本就跨甲宽松，此点可参考做武器解限。

## 17. 传家宝改造（符文激活）

- 原版传家宝改为**金币购买 + 指定符文激活**（物品说明标注所需符文号），激活后升级成长。
- 把"传家宝"变成中期目标物而不是白送。

## 18. 随身小伙伴（便利性）

- 随身**商人/职业训练师/专业训练师/传送大师**做成可召唤小伙伴（`60009 技能书：随身商人`），飞龙坐骑 +30% 速度。
- 传送只能传**副本门口**（配合门控体系，不破坏探索）。
- 1.12：Eluna 已实现炉石传送菜单（super_hearthstone.lua），可直接扩展"召唤商人/训练师"。

## 19. 新手引导（艾薇儿）

- 进游戏找 **艾薇儿**（NPC 190002/190003）接引导任务链：新手村几个任务 → 奖励 普通商人/训练师/传送大师/赫拉迪克方块/飞龙。
- 1.12 可完全用 Eluna welcome.lua 扩展（现有登录欢迎已就绪）。
