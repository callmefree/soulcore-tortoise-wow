## 七、已知坑 / 运维要点

- `soulcore.asia` 有 IPv6，SSH/paramiko 必须强制 IPv4（各脚本已处理 `getaddrinfo(AF_INET)`）。
- MariaDB 只监听 127.0.0.1，远程改库走 SSH 隧道或本地 `--mysql` 方式。
- Linux 二进制依赖 `libACE-7.0.6.so`；新二进制直接取 `weekly-build.yml` 最新成功 artifact。
- 客户端改 DBC 后删除 `WTF/`/`WDB/` 缓存；`/reload` 不更新 DBC。
- Eluna 布尔事件语义与官方相反（item use 返回 false 才阻止施法）；gossip 先 `GossipClearMenu()`。
