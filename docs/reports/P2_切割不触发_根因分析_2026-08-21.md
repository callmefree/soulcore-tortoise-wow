# P2 切割附魔"不触发"根因分析（2026-08-21 16:51 用户反馈）

## 结论先行
切割（Slice and Dice）附魔"不触发"不是 P2 池本身出错，而是 **P2 池沿用了 v2 重构前的精炼池（r4），其中两类 SIE 存在"无效/不符合预期"**，切割恰好落在两类上。全池受影响规模 **3072 条（17.8%）**。

## 根因 1：learn 型漏网（2439 条）— 切割所属
- 切割 SIE：`92120 → spell 5175`、`93448 → spell 6775`，两条都是 **effect36 LEARN_SPELL**（装备时施放 → 永久学会技能 5171/6774）。
- 学会的"切割"是**盗贼主动 buff**（spellFamilyName=8 ROGUE，攻速 +19%/+29%），**必须手动使用**，不会自动触发；非盗贼角色学会也无法使用。
- 用户预期"随机词缀 = 装备被动生效"，learn 型给的是"教主动技能" → 错位。
- 规模：2439 条 SIE（834 个 learn 法术）→ 装备教技能（含背刺/斩杀/庇护/属性被动等）。

## 根因 2：容器 trigger 空壳（633 条）— 切割的另一半
- 容器型切割：`92117 → 205171`、`93195 → 206434`、`93447 → 206774`（[RC] 容器，aura42 PROC_TRIGGER）。
- 但 trigger `300945`/`301649`（[RE] Slice and Dice）是 **effect1=3 DUMMY**，SpellEffects.cpp **无 DUMMY 脚本 hook** → proc 触发空转，无效果。仅 `301508`（aura138 攻速 +29）有效。
- 规模：633 条 [RC] 容器 trigger 为 DUMMY/空（含 Execute 斩杀 205308→301004 等）。
