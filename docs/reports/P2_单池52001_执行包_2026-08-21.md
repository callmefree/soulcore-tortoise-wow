## 1. 机制裁决（内核源码级确认，写死为基线认知）

```
random_property(池ID)
  → item_enchantment_template 按 chance 加权抽 ench
  → LookupEntry(ench) 查 IRP —— ★IRP ID 必须 == ench，否则白板 + 日志报错
  → randomPropertyId = IRP ID（写入 item_instance）
  → 3 个 PROP 槽 = IRP.enchant_id[0..2]（真实 SIE 效果）
  → 客户端按 IRP.nameSuffix 拼后缀名
```

- **权重表 ench 填任意 IRP ID 均可**：454 基线池用 SIE ID 镜像段（5/15/16/19…），P1 用独立段（51001-51003），P2 用 52001 段。
- IRP 结构（DBCStructure.h）：16 字段 64B/条 = ID / internalName / enchant_id[3] / 2 空 / nameSuffix[8] / flags。
- 证据：`Item.cpp:GenerateItemRandomPropertyId`（soulcore 与 oyturtle 一致）+ 454 池实测 ench=5/15/754/839…。
