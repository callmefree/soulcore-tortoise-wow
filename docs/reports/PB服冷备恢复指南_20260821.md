## 恢复步骤（灾难恢复时执行）
```bash
# 0. 备份介质：FNOS 路径 /vol1/1000/魔兽世界/1.18冷备/2026.08.21 PB服/
# 1. 停服（需 sudo，administrator 非交互 systemctl 会触发 polkit 认证失败）
echo <口令> | sudo -S systemctl stop pbmangosd pbrealmd 2>/dev/null

# 2. 拉回并解包核心文件（游戏服上执行）
scp -i /home/administrator/.ssh/id_ed25519_fn -o StrictHostKeyChecking=no \
  "<口令>@192.168.1.2:/vol1/1000/魔兽世界/1.18冷备/2026.08.21 PB服/pb_core_20260821.tar.gz" /tmp/
tar xzf /tmp/pb_core_20260821.tar.gz -C /opt/soulcore-pb/server/

# 3. 导入数据库（root 密码 <口令>）
mkdir -p /tmp/pb_restore_db && cd /tmp/pb_restore_db
scp -i /home/administrator/.ssh/id_ed25519_fn -o StrictHostKeyChecking=no \
  "<口令>@192.168.1.2:/vol1/1000/魔兽世界/1.18冷备/2026.08.21 PB服/db/*.sql.gz" .
for db in tw_pb_logon tw_pb_world tw_pb_char tw_pb_logs; do
  gunzip -c "$db.sql.gz" | mysql -uroot -p<口令> "$db"
done

# 4. 起服并验证
echo <口令> | sudo -S systemctl start pbmangosd pbrealmd 2>/dev/null
systemctl is-active pbmangosd pbrealmd
```

## 一致性校验方法
- DB 行数：`mysql -uroot -p<口令> -e "SELECT COUNT(*) FROM tw_pb_world.item_template"`
- gz 完整性：FNOS 上 `gzip -t "/vol1/1000/魔兽世界/1.18冷备/2026.08.21 PB服/db/"*.sql.gz`
- tar 可读：FNOS 上 `tar tzf "/vol1/1000/魔兽世界/1.18冷备/2026.08.21 PB服/pb_core_20260821.tar.gz" | wc -l`（应为 423）
